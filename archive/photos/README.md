# Family photographs

Original photographs kept by the family. Real photographs always come before generated illustrations.

Each photo gets a folder `archive/photos/PNNN/` holding `photo.yml`: what it shows (only what is visible or known from the family), who supplied it, any date or place the family can confirm, and permission to publish. The image itself is committed only once the family approves publishing it, as a reduced web copy with metadata stripped.
